System Architecture

End-to-End Clinical Data Pipeline

📥

1. Ingest & Archive

Audits raw CSVs, enforces strict schema types, flags malformed entries, and captures immutable timestamped snapshots in the raw layer.

🛡️

2. Quality Validation

Calculates data quality scores, detects duplicates and nulls, and verifies physiological boundaries (e.g., blood pressure, serum cholesterol).

🧬

3. Clinical Enrichment

Computes 14 derived clinical features including BP stages, cholesterol categories, age brackets, and multi-factor composite risk indices.

📦

4. Parquet & DuckDB

Exports high-density columnar Parquet files for vectorized SQL analytics with DuckDB, achieving zero-server relational queries.

🔥

5. Firebase Integration

Static landing page hosted on Firebase Hosting with zero cost (Spark plan), backed by Firestore data sync and security rules.

📊

6. Tableau & Flask Dashboards

Embeds interactive Tableau public workbooks alongside local Flask operational dashboards for live cohort exploration.
